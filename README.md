# MysticRoyalSkin Minecraft Texture

MysticRoyalSkin is a Minecraft skin texture design featuring a black hoodie, red eyes, dark pants, and a gold crown. It is supplied as a 64×64 SVG texture source for a Minecraft character skin.

## Install

1. Download `assets/textures/black-hoodie-crown-skin.svg`.
2. Convert the SVG to a 64×64 PNG using an image editor or converter that preserves transparency.
3. Upload the PNG through the custom skin option available in your Minecraft edition or platform.

## Use

1. Open your Minecraft profile or skin settings.
2. Choose the custom skin upload option and select the converted PNG.
3. Apply the skin and check its appearance in-game.
